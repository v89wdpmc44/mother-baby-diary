# 【科普】呼吸道合胞病毒高发期，我们应该怎么办？

> 更新时间：2026-09-11 (UTC+8)

天气转冷，呼吸道传染性疾病进入高发期。一种具有高度传染性的病毒——**呼吸道合胞病毒**，正悄悄袭击婴幼儿群体。许多家长对这种病毒有所耳闻或有所了解，形成了一定恐惧心理。我们需正确认识呼吸道合胞病毒，科学防治，力保平稳度过高发期。

呼吸道合胞病毒（RSV）是一种单链RNA病毒，通过飞沫和密切接触传播，感染后潜伏期通常为2-8天。在我国北方，流行季通常从10月持续到次年3-4月份。呼吸道合胞病毒感染后不能产生永久性免疫，所以可能会反复感染，但通常首次感染症状最重。

**感染后有哪些症状？**

它能导致所有年龄段人群感染，但却是引起5岁以下儿童急性下呼吸道感染的重要病原体。早期症状与普通感冒相似，若感染后沿呼吸道向下走，引发细支气管炎或肺炎，是我们需要特别注意的。

**轻度症状**：

鼻塞、流涕、咽痛、咳嗽、伴或不伴发热、声音嘶哑等。

**重度症状**：

呼吸系统症状：咳嗽加重、喘息、呼吸急促、三凹征（呼吸时胸骨、锁骨上、肋间隙凹陷）、鼻翼扇动或呻吟等。

喂养困难：吃奶减少或异常哭闹。

精神状态：烦躁不安、嗜睡、昏迷等。

家长注意，**若孩子出现以下症状，务必及时就医**！

体温＞38.5℃，高热不易退或反复发热；

咳嗽逐渐加重，甚至出现喘息、憋喘、呻吟；

张口呼吸，鼻翼煽动，锁骨上窝、胸骨上窝、肋骨间隙或胸廓下方肌肉向内凹陷；

烦躁哭闹、精神状态差；

食欲降低或拒食，伴脱水表现。

**如何治疗和预防？**

治疗上，目前呼吸道合胞病毒感染尚无特效治疗药物，以对症支持治疗为主：

1.**退热镇痛**：如发烧不适，可按医嘱使用退热药物，结合物理降温。

2. **缓解鼻塞**：可使用生理盐水喷鼻、洗鼻，保持呼吸道湿润。

3. **保证液体摄入**：少量多次地喂水、喂奶，防止脱水。

4. **保持空气湿润**：可使用加湿器，有助于缓解咳嗽和鼻塞症状。

5. **密切观察**：重中之重！时刻关注孩子的呼吸和精神状态等。

预防上，尽量做好日常防护：

1. **勤洗手**，可使用肥皂和流动水或含酒精的洗手液。

2. **不聚集**，尤其是尽量不带婴幼儿去人员密集场所。

3. **定期清洁和消毒**婴幼儿的玩具和衣物。

4. 家庭成员出现感冒症状时应**佩戴口罩**，并避免接触婴幼儿。

5. 另外，**不建议**家长一回家就对着孩子抱抱亲亲，因为家长可能携带病毒但没有症状，建议做好洗护消毒后再接触孩子。

**预防接种**

对于0～12月龄宝宝来说，注射「合胞病毒预防单抗」是预防呼吸道合胞病毒的有效手段，尼塞韦单抗等单克隆抗体可有效降低宝宝感染风险，单次注射能提供至少5个月的保护，覆盖整个流行季，并能降低重症风险，安全性良好。建议家长根据宝宝情况，在医生指导下及时接种。

RSV虽传染性强，但通过做好个人卫生、环境清洁、避免接触传染源等措施，可显著降低感染风险。感染后多数人症状较轻，但需密切关注高危人群及重症信号，及时就医可有效控制病情。科学防护、理性应对，不必过度恐慌。
